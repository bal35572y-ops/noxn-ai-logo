NOXN AI LOGO — دليل البدء السريع

محتويات المشروع:
- index.html: واجهة الموقع.
- style.css: التصميم المتجاوب.
- app.js: التفاعلات ومعرض التصاميم المحلي.
- netlify/functions/generate.mjs: خادم آمن يطلب الصور من OpenAI.
- netlify.toml: إعدادات نشر Netlify.

مهم قبل النشر:
1) أنشئ حساباً في Netlify.
2) ارفع مجلد المشروع أو ZIP إلى Netlify.
3) افتح إعدادات الموقع Site configuration ثم Environment variables.
4) أضف متغيراً اسمه OPENAI_API_KEY وضع فيه مفتاح API الخاص بك.
5) أعد نشر الموقع Deploys > Trigger deploy.
6) اختبر إنشاء صورة من الموقع.

تحذير:
- لا تضع مفتاح API في index.html أو app.js.
- واجهة OpenAI API تحتاج حساب API وفوترة/رصيداً متاحاً؛ اشتراك ChatGPT لا يتضمن تلقائياً رصيد API.
- كل عملية توليد قد تستهلك رصيداً حسب النموذج والحجم والجودة.
- معرض الأعمال في هذه النسخة يحفظ على نفس المتصفح/الجهاز فقط. لا توجد قاعدة بيانات أو حسابات مستخدمين بعد.
- لا تشارك مفتاح API مع أي شخص.

هذه نسخة البداية (MVP). أدوات التوليد تستخدم وصفاً مخصصاً لكل نوع، أما رفع الصور للتعديل، تسجيل الدخول، المزامنة السحابية، الرصيد والاشتراكات فتضاف في مراحل لاحقة.
